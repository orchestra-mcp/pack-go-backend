# orchestra-mcp/pack-go-backend

Go backend skills and agents for Fiber, GORM, and REST APIs

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-go-backend
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-go-backend")
```

## Contents

| Type | Names |
|------|-------|
| Skills | go-backend |
| Agents | go-architect, qa-go |
| Hooks | None |
